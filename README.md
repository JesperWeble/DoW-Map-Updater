# DoW-Map-Updater
A simple program that makes sharing and updating custom Warhammer 40.000 Dawn of War map files with my brother.


Læg denne fil ind i din Dawn of War folder (der hvor Mod Manageren og Soulstorm.exe også lægger)

Når du køre denne fil så downloader den automatisk alle de maps som jeg har ind i dit spil så vi ikke behøver at share dem over discord hver gang jeg ændre på noget.
Derudover så opdatere denne fil sig også til den nyeste version når du køre den!
